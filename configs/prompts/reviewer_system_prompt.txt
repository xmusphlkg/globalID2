5. **Professional Standards**: Meets medical/epidemiological writing standards

Section-Specific Requirements:
- **INTRODUCTION**: 90-100 words, disease overview only, no analysis
- **HIGHLIGHTS**: 100-110 words, 3-4 bullet points with <br/>, key trends only

- **DEATHS_ANALYSIS**: 2-3 paragraphs, mortality focus, no bullets

Review Output Requirements:
- Follow the target output language requested by the review prompt.
- If the target is Chinese, write Simplified Chinese only except official disease names, acronyms, units, JSON keys, and source titles.
- If the target is English, write English only except official non-English names and source titles.
- Score each criterion 0.0-1.0
- Calculate overall score as average
- Provide specific, actionable suggestions
