# 2026-11-23 采集后续修复

## 问题与行为变化

### 图片审核恢复

省级采集在视觉模型不足时仍可能完成正文入库，但图片报告留在 `needs_review`。
旧的失败任务重试只处理 `FAILED`，因此模型恢复后不会继续这些图片。
16:47 的只读核查识别出陕西 3、甘肃 6、青海 2、新疆 3 份此类报告。

新增恢复流程只选择尚未投票、原因明确为缺少不同视觉模型的报告；固定多数票门槛不变。
模型容量恢复后，调度器创建关联原任务的新任务，验证并复制归档文章、原图和采集计划，
离线重新审核。每条恢复链最多两次，分别等待 5、10 分钟；历史任务与正常周调度保留。
暂停、最新配置、最新任务、执行 attempt、归档完整性和摘要均在相应阶段重新检查。
投票分歧、弃权、修订冲突或原图缺失不进入此自动恢复流程。

### 挪威官方统计接口迁移

旧的 `allvis.fhi.no/api/msis/kodeverk/diagnoser` 返回 301，跳转至
`statistikk.fhi.no` 后得到的是前端 HTML。官网公开配置指向
`https://statistikk-data.fhi.no`，但新后台的旧 API 路径也不可用。

新适配器沿官网实际菜单发现月度病例表，通过
`/api/open/v1/msis/Table/{table_id}/data` 查询 JSON-stat2。校验病种、月份、全国、
全年龄、全性别和病例数维度，排除菌株计数和结核预防治疗。重复表的同病种同月数值
必须相等才能去重；空白、稀疏缺项及带状态的受抑制单元格不转成零。
表的未覆盖月份和有明确起止年份的历史专题分别记录审计。

通用采集证据补存脱敏后的原请求 URL、HTTP 状态、请求方法及 JSON 请求摘要，
使重定向和同一接口的不同 POST 查询能够准确离线重放，且保留原 HTTP 错误。
旧 CSV 回退仅作为诊断证据，不再覆盖已经更新的数据库事实；校验失败的实时数据
不能继续作为可用数据选中。

注册表补充 10 个病种名称的安全别名，其中 8 个已有规范疾病目标；GBS 和结核预防治疗
仍保持原来的无规范疾病投影规则。E. coli 的新拆分项、病毒性中枢神经感染的病原分项等
不合并进旧总项，保留来源原生类别及其审核边界。

### 来源健康状态

非省级来源的健康状态现在批量读取最新任务、最高执行 attempt 的整理审计，
只投影状态字段。`partial` 和 `needs_review` 不再因任务完成而显示为健康。
更高 attempt 仅执行采集时，不继承旧整理阶段的审计；暂停、运行、失败及既有省级规则保留。

泰国 DOE506 的 15:59 批次处理 864 行，来源审计为 `partial`：144 条错误记录包含
72 条 HTTP 404 和 72 条年度文件尚未覆盖完整年度。它们不是 144 个失败任务，
本次面板修复也不代表这些上游缺项已经补齐。
