# 中国31省数据缺口、更新机制与识别问题审计（2026-11-15）

本次核对当前数据库、31个省级适配器、控制面调度，以及各配置栏目最新一份官方报告，并对北京、海南、山西等做了定点补验。结论是：**历史覆盖广，持续更新未形成闭环；部分地区已有可解析的新表却未入库，部分地区的“解析成功”只代表少量零值，且存在可复现的串病和时间口径错误。**

范围为本项目31个省级适配器，包含省、自治区、直辖市；香港、澳门、台湾不在这31个适配器统计中。审计时区为Asia/Shanghai。执行的是数据库只读查询、网页抓取、离线解析和既有测试，未导入数据、修改采集代码或启用调度。

## 证据口径与总览

- 原始事实158,501条：数据中心134,882条，省级月报23,619条；公共投影155,319个点。来源重叠与投影规则使二者不应直接等量比较。
- 31省都有2004—2021历史月份；只有20省有2022年后的任何观测，只有16省有2026年的任何观测。北京、天津、河北、内蒙古、吉林、山东、湖北、云南、西藏、陕西、宁夏这11省的最新入库月仍为2021-12。
- 当前数据库共有73个自动任务，`automation_jobs.country_code LIKE 'CN-%'`为0，对应调度状态和`crawl_runs`亦无记录。当前控制面未配置省级自动采集，仓库未发现替代省级定时入口；这不排除外部主机或人工导入，也不表示历史从未抓取。
- 当前配置现网探测：22省可产生行，6省详情解析无值，2省栏目访问失败，1省未接入。22省中17省来自表格/附件，5省只有稀疏正文结果。额外补验北京正确首页后，可从2026-09附件解析55行。
- 31省公共投影的最新月份与原始事实一致，本地国家JSON的最新月份也一致。因此本轮观察到的月份滞后主要发生在发现、解析、入库之前；本次没有验证线上发布版本。
- 省级来源注册的109个系列全部是`case_notifications`。死亡数没有独立入库系列，即使原始附件含死亡列，当前覆盖仍只有发病/报告病例；不能把展示层累计死亡0理解成真实零死亡。
- 数据中心本次`available_years()`返回2004—2021。该函数结合目录与后续年份“痢疾1月”探测，并非穷举所有病种月份，故结论是“当前机制未发现2022年以后的可用年份”，不是证明上游绝无更多数据。

表中“2022后有值月”以2022-01至2026-10共58个月为窗口；只要任一疾病有一条观测即计1月。**有值不代表该月病种齐全，缺月不代表来源未发布，缺行也不是零。** 10月已结束但部分来源仍在发布时滞内，不能一律视作超时故障。现网“最新”只表示配置栏目发现的最新月，不能据此认定全网没有更新。

[逐省CSV](data/cn_province_coverage_20261115.csv)含2022年后完整缺月列表及2026逐月行数；[审计证据JSON](data/cn_province_audit_20261115.json)保留只读SQL、来源分组覆盖、现网URL/时间/SHA、补验证据及识别复现。

## 处理顺序与验收

1. **先修识别正确性**：别名子串、病例/死亡与本月/累计列、正文时间范围；逐月审查山西9条证据关联。验收应增加上述真实及合成反例，不能只看既有测试通过。
2. **优先恢复可直接获取的数据**：北京改正确首页，天津和云南接通持续入库，海南接WPS路由；辽宁/重庆/广西补到10月，安徽/福建补到09月，浙江复核06—08月，其余可解析省补近期积压。每月先做原表行数与字段核验再入库。
3. **建立调度与缺月队列**：按省、来源、疾病和报告期建覆盖状态，区分整月无记录与病种稀疏；历史回补基于完整分页，不能仅反复取最近3条链接。
4. **解决源发现与格式障碍**：河南、江西、新疆、贵州查栏目迁移；河北、青海处理访问问题；陕西、甘肃接图片表审核流程；内蒙古、吉林、湖北、山东、宁夏寻找完整明细；西藏完成来源发现。
5. **补死亡指标并贯通发布**：病例/死亡各自保存，缺死亡保持未知；库内更新后检查公共投影、导出和线上版本。疾病覆盖须按该省该月官方实际目录验收，不能统一要求49或55行，也不能因行数达到阈值就认定完整。

建议每省验收字段：`last_checked_at`、`latest_discovered_report_month`、`latest_ingested_month`、`latest_published_month`、`missing_months`、`missing_disease_series`、`evidence_type`、`completeness_status`、`last_error`。完整表、部分表、正文稀疏、访问失败、尚未接入必须区分；运行时间更新不代表数据月份更新。
