# 月度监测算法信号：离线试点

本功能读取本地国家快照中的独立 `source_series`，输出候选与跳过原因。
不读取数据库，不请求网络，不发送通知，不修改既有报告或公共风险等级。
结论统一标注“算法信号，非官方确认”。周度、年度和没有来源序列的兼容投影暂不参与。

## 使用

从仓库根目录运行，明确给出评估日期。JSON 输出到标准输出，可保存到忽略的
`exports/`，不要将国家数据或完整结果提交到应用仓库。

```bash
mkdir -p exports/signal-pilot
venv/bin/python scripts/evaluate_surveillance_signals.py \
  astro-site/src/data/countries/au.json --as-of 2026-11-15 \
  > exports/signal-pilot/au-latest.json

venv/bin/python scripts/evaluate_surveillance_signals.py \
  astro-site/src/data/countries/au.json --as-of 2026-11-15 --replay \
  > exports/signal-pilot/au-replay.json
```

`--sigma`、`--minimum-increase` 和 `--minimum-ratio` 可改变试验阈值；
结果保留完整 policy、输入文件 SHA-256、快照生成时间、基线日期与评估日期。
输入错误会非零退出。没有合格序列仍会成功输出解释，不能将 skipped 当成正常或零病例。

## 资格与阈值

- 按来源序列、地理键、人群维度和病例定义版本分别计算，不拼接不同来源或合并疾病；
  结果保留 `selection_key`、`dimension_key` 与 `dimensions`，同一序列的不同人群可辨识。
- 只接收有完整身份的月度 `case_notifications`、单位 `count`，声明口径断点的序列跳过。
- 每个来源月份唯一；日期、值、逐点质量数组须等长。非有限数、负值、非整数、缺失值不当成零。
- `raw`、`final`、`validated` 质量可参与内部试验；`provisional`、未知和其他质量跳过。
  `raw` 代表尚未确认为终值，试验不因此保证来源准确性。
- 当前月份未结束则跳过；最近观测的期末距评估日期超过 62 天则跳过。
  最新观测缺失或质量不合格时，不悄悄回退到更早的有效月份。
- 最近 12 个月至少有 10 个合格观测；基线为此前最多 5 年的相同日历月，至少 3 个。
- 当前值必须严格超过以下三项的最大值：同期均值加 2 个样本标准差、同期均值加 10、同期均值的 1.5 倍。
  零方差基线仍应用绝对和比例门槛，不生成虚构 Z 分数。

这些参数是待校准的试验设置。低计数疾病可能因此被漏掉；单月候选尚未加入连续性判据、
多重检验控制、报告延迟校正或人工复核闭环。

## 回放含义

`--replay` 按月份使用更早年份的观测计算，不读取该观测之后的值作为基线。
历史月份以紧接期末的日期计算，当前月份仍遵守明确的 `as_of`。

输入是**当前快照**，可能含多年后的补报和修订。来源实际发布日期和各时点历史快照未提供，
所以回放不等于当时可收到的告警，不可据此报告提前量、灵敏度或误报率。
`candidate_rate` 仅表示合格月份中触发规则的比例；没有疫情真值标签。

## 2026-11-15 本地试验

本轮读取工作区当时的 AU/HK 国家快照，未访问线上控制面。首次结果如下，
完整输入指纹与逐条结果位于忽略目录 `exports/feature-pilot-20261115/`。

| 样本 | 结果 |
| --- | --- |
| AU 历史回放 | 3,863 个可评估来源月份，327 个候选，候选率 8.46%；另有 637 个跳过项，含历史不足、近期覆盖不足和无注册来源的疾病。 |
| AU 最近观测 | 0 个合格；15 项近期覆盖不足，1 项过期，56 项无注册来源。 |
| HK 最近观测 | 0 个合格；4 项数值或质量不合格，6 项过期，60 项无注册来源。 |

这是单次本地快照诊断，不是国家整体数据质量评级，也不是实时线上状态。
后续应选定少数来源，核实缺失月份、修订规则、质量标记与发布时间，
保留逐次快照并由人工标注候选，观察一段时间后再决定是否接入公共页面或邮件。
