## 验证证据

- 公共站点 `npm run test:public`：55 项通过，包含病原体映射、RSS 选择项、宿主过滤与三语计数。
- 公共站点 `npm run check`：519 个文件，0 errors、0 warnings、14 个既有 hints；样式边界通过。
- 月度信号工具：34 项聚焦测试通过，包括同一来源不同人群的结果身份、未来值隔离、缺失/零和 CLI 输入指纹。
- 最终整合 Python：10 个测试文件共 176 项通过，包含上述 34 项算法测试、宿主、feed 导出、原文抽取、存储、发布校验、独立 JSON publication 和订阅发布边界；含迁移默认值/回滚、宿主隔离及重复重抽 ID 复用。
- RSS：Worker 32 项单元测试、类型检查和 dry-run 打包通过；真实 Miniflare runtime 5 项通过、1 项既有跳过，覆盖 gzip R2 对象、跨代读取、ETag、HEAD 和空数据/不可用的区别；本地 AU 公开通报三语 RSS 各 7 条通过 XML 解析。
- `alembic heads` 显示单一头 `0032_situation_host_metadata`；本检查只读迁移图，未应用数据库变更。

本轮第一次 Astro 检查发现 RSS 选择项的两个类型错误，修复并重跑后通过。
subagent 交叉复核发现算法结果遗漏人群维度身份，已补齐字段和回归。
最终补充区分宿主范围不适用与确实缺少人类序列的提示，相关前端回归及两文件 TSX 编译通过。
没有执行仓库全部测试或生产浏览器交互验收。

本地 AU/HK 快照试验的完整结果位于忽略目录 `exports/feature-pilot-20261115/`，
每份结果保存输入 SHA-256。AU 历史可评估 3,863 个来源月份，327 个候选；
当前 AU/HK 最近观测未通过全部门槛。候选比例不是误报率，详见算法说明。

## 发布依赖

1. 先应用 Alembic 0032，再加载查询新字段的后端代码。迁移只为历史记录设置未知宿主。
2. 抽取 v4 可触发既有旧提示词重排队机制，应观察模型容量；公开历史原文读数在新结果通过复核前保留。
   唯一兼容记录保留 `alert_id`，人兽拆分/物种变更使用独立 ID；宿主重分组可能改变 `outbreak_id`。
3. 使用既有发布工作流生成新 Situation 代，包含 `feed.json`，并完成源数据与公开检查。
4. 发布数据 Worker 与站点模板，核验 zone Worker 和 Pages 打包 Worker 均含 RSS 路由。
   只更新 HTML 无法生成新 feed 对象；只更新数据也不会添加模板上的资源面板和入口。
5. 以三语页面和真实来源核验宿主、计数、原文链接及 RSS 同代读取。邮件试点单独记录收件证据。
