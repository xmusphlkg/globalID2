## 按优先级处理

1. **P1，rc.5：`stale_source` 与 API 枚举不一致。** 省级来源落后超过三个月时，健康函数产生 schema 不接受的状态，可能使整份自动化配置/作业列表返回失败。优先统一服务、Pydantic、OpenAPI、生成类型及消费端，并补端到端 response 合同测试。
2. **P2，rc.1：NL/MY 数值撤回变缺失后仍残留旧值。** 明确单元格 blank/null 被直接跳过，共享 upsert 无法收到撤回事实。
3. **P2，rc.2：具体日/短区间正文误归整月。** `10月15日`、`10月1日至10月7日` 的病例可被赋到月初。
4. **P2，rc.2：病例缺失吞掉明确死亡值。** 同行 `病例='-'、死亡=2` 被整体丢弃，应按指标保留证据。
5. **P2，rc.2：补充附件失败丢弃有效 HTML 表。** 多载体遍历新增路径在单个附件 404 时使整份报告失败。
6. **P2，rc.5：暂停竞争仍可误入队一次。** 最终刷新已看到 `next_run_at=NULL`，仍因使用旧 enabled 快照而入队。
7. **P2，rc.5：通知 opt-out 中途提交释放未领取事件锁。** 混合批次中的正常事件仍为 pending 就提交，存在并发重复领取窗口；本轮只验证事务边界，未真实发信。
8. **P2，rc.4：宿主物种分组规范化不一致。** `Wild birds` / `wild birds` 聚为同一疫情，却导出两个地点，首页与地图计数不一致。
9. **P2，rc.3：地图色阶计算阻塞主线程。** 美国 D094 纯函数独立复测约 2.4–2.7 秒，切换范围会重算完整历史。
10. **P2，rc.1：TH 最新周策略与完整修订/自动恢复承诺不一致。** 需要实现追赶窗口，或明确收窄统一自动化文档的承诺；专用来源文档已说明最新一周策略。
11. **P2，rc.1：CO 新门禁与旧测试断言不一致。** 保留完整历史门禁并更新回归合同；不得为消除失败恢复旧单页路径。
12. **P2，rc.6：PE 新测试原档超过 5 MiB 代码仓库上限。** 两个 fixture 分别为 8,557,778 和 5,812,723 bytes，原样提交会触发门禁；未跟踪生成物也需排除。

各项准确文件/行号、触发条件、证据及建议在分报告中。主 agent 已独立重跑 rc.1、rc.2、rc.4、rc.5 反例及 rc.3 性能采样，结果一致。
