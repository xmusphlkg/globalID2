# 中国省级图片与扫描件：AI 专家投票验收

2026-11-16，范围为中国省级月报的图片和扫描 PDF。省级图片链路直接识别原件，不调用 OCR。

## 实现

- `cn_provinces.py` 捕获正文图片、懒加载图片、链接的原图和扫描 PDF；原有 HTTP 归档保存源文件。HTML/附件表格成功不会跳过其他载体；混合 PDF 不只采纳有文本层的一页。
- `document_images.py` 只包装原图为无文字层 PDF，保留方向、透明度和多帧顺序，设置字节、页数、像素上限，与既有 PDF 处理共用线程锁。
- `cn_province_image_review.py` 通过模型中心持久队列，逐专家独立读取相同原件，不提供他人答案。按实际模型身份去重，强制调度避让已投模型，不使用独立客户端或密钥。
- 默认固定 3 席、2 票多数；可配置 5/7 席。无效输出、文本降级、重复模型、调用失败、缺席均不得缩小分母。仍有可用模型时不因已有多数而跳过后续席位。
- 投票按整份报告的语义指纹进行，包括疾病值、列语义、父子关系、类别合计、页码和脚注；不按单元格拼凑。有效票必须先通过严格结构、地区/月度、完整页面、病种注册与定义、非负整数、显式印刷合计等检查。
- 源表甲乙类合并时保留合并分组；病名别名使用现有确定映射。未知病名、空白、缺页和合计不符不推算补全。
- 整理使用原件归档离线重放；模型调用在提交事务之外。未达多数保持 `needs_review`；同月来源冲突隔离该月，已有 `revised`/`final` 事实受原提交门禁保护。
- 全部逐模型读数、弃权原因、投票指纹和原件来源保存在任务/阶段审计；每条事实只保留对应行及审计 SHA 回执，避免重复存整份报告。

## 复现

```bash
venv/bin/python scripts/review_cn_province_images.py \
  --province CN-QH --month 2026-10 \
  --document data/processed/cn_province_repair_20261116/image_review/CN-QH_202610_page1.jpg \
  --source-url http://www.qhcdc.org.cn/upload/main/contentmanage/article/image/2026/11/05/c026199ce1284a88b8492a06e14200b6.jpg \
  --article-file data/processed/cn_province_repair_20261116/image_vote/CN-QH_202610_article.txt \
  --output NEW_REVIEW.json --live --panel-size 3
```

通过返回 0；未达多数或超时返回 2。此命令只生成审计，不导入业务数据。不加 `--live` 仅输出原件清单。
